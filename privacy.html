Política de Privacidade

Última atualização: 08 de agosto de 2026

1. Introdução

Este aplicativo ("HTTP Inspector" / "Matrix Bot") foi desenvolvido como uma ferramenta de diagnóstico e aprendizado para desenvolvedores web. Esta política descreve como coletamos, usamos e protegemos suas informações.

2. Dados que coletamos

Nosso aplicativo pode coletar as seguintes informações:

  • Entradas do usuário: Os sites ou domínios que você insere para consultar os cabeçalhos HTTP.
  • Resultados de diagnóstico: Os cabeçalhos HTTP retornados pela API de terceiros.
  • Dados de interação: O conteúdo das conversas com a inteligência artificial integrada.

3. Como usamos seus dados

Os dados coletados são utilizados estritamente para:

  • Executar a consulta de cabeçalhos HTTP solicitada pelo usuário.
  • Treinar e melhorar a lógica de IA para conversas.
  • Armazenar o histórico de consultas em nosso banco de dados na nuvem (MongoDB) para que o usuário possa ter um registro de suas verificações.

4. Compartilhamento de dados

Não vendemos, trocamos ou transferimos suas informações pessoais para terceiros. Para executar as funções do app, utilizamos APIs de terceiros (como Hugging Face para a IA e HackerTarget para as consultas HTTP), que possuem suas próprias políticas de privacidade.

5. Armazenamento e Segurança

Seus dados de consulta são armazenados de forma segura em servidores na nuvem (MongoDB Atlas e Render). Adotamos práticas de segurança padrão para proteger as informações contra acesso não autorizado.
